## Instructions to convert the **HireForge Pro** Project to Full Stack Dev Project:

### **NOTE**: Current code of FastAPI present in this repositiory is the backend of this project. No need to change or modify this code. Don't touch this code.

- Use Modern Tech for Creating UI. Don't just use "Node.js" and same design like any other AI Model for UI.

- Create a `user_auth` like **signin with google** if the user is new or **login with google** if he is an existing user. For a new user, make him to create profile.

- Do include job CRUD (create/edit/delete job postings) for the recruiter. 

- Create a Database using sqllite from python for every user. it should contain the user name, email/gmail id, password, any jobs that the user created, candidate's resumes, status of the candidate for tracking candidate's (resume's) progress.

- create a dashboard for recruiters that shows all the jobs that they created (either in container/card manner or list manner) by clicking which, they gets the top resumes ranked by the usual backend code.

**I activated the virtual env using `uv`. So, for any tasks, use this package manager only.**
